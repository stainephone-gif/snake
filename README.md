# 🐍 NEON SNAKE - Киберпанк Змейка

Современная мобильная версия классической игры "Змейка" с уникальным неоновым дизайном в стиле киберпанк и необычными игровыми механиками.

![Version](https://img.shields.io/badge/version-1.0.0-brightgreen)
![Platform](https://img.shields.io/badge/platform-Android-green)
![Made with](https://img.shields.io/badge/made%20with-Cordova-blue)

## ✨ Особенности

### 🎨 Уникальный дизайн
- **Неоновый киберпанк стиль** с яркими градиентами
- **Анимированные эффекты** свечения и пульсации
- **Плавные переходы** между экранами
- **Адаптивный интерфейс** для всех размеров экранов
- **Темная тема** с неоновыми акцентами

### 🎮 Инновационные механики

#### 🌀 Порталы
- Два портала на игровом поле
- При прохождении через портал змейка телепортируется ко второму
- Открывает новые стратегические возможности

#### ⚡ Power-ups (Усиления)
1. **🛡️ Щит** - защита от одного столкновения (со стеной, препятствием или собой)
2. **🧲 Магнит** - автоматическое притягивание еды в радиусе 3 клеток
3. **×2 Удвоенные очки** - двойные очки за каждую съеденную еду

- Power-ups появляются случайно (30% шанс после поедания еды)
- Активны 15 секунд
- Можно накапливать несколько одновременно

#### 🧱 Препятствия
- Неподвижные препятствия на поле
- Количество зависит от сложности
- Требуют стратегического планирования маршрута

### 🕹️ Управление

#### Свайп-управление
- **Свайп вверх** ⬆️ - движение вверх
- **Свайп вниз** ⬇️ - движение вниз
- **Свайп влево** ⬅️ - движение влево
- **Свайп вправо** ➡️ - движение вправо

#### Клавиатура (для тестирования в браузере)
- **Стрелки** или **WASD** для управления

### 🎯 Уровни сложности

#### 🟢 Лёгкая
- Скорость: медленная (200ms)
- Проход через стены (выход с одной стороны = появление с другой)
- Нет препятствий
- Идеально для новичков

#### 🟡 Нормальная
- Скорость: средняя (150ms)
- Стены смертельны
- 3 препятствия на поле
- Сбалансированная сложность

#### 🔴 Сложная
- Скорость: быстрая (100ms)
- Стены смертельны
- 6 препятствий на поле
- Для опытных игроков

### 📊 Система прогресса

- **Счёт очков**: 10 очков за еду (20 с удвоением)
- **Рекорды**: автоматическое сохранение лучшего результата
- **Статистика**: количество сыгранных игр
- **Локальное хранилище**: все данные сохраняются оффлайн

### 🔊 Звук и тактильность

- **Вибрация** при важных событиях:
  - Поедание еды - короткая вибрация
  - Активация power-up - тройная вибрация
  - Потеря щита - двойная вибрация
  - Game Over - длинная двойная вибрация

- **Настраиваемые параметры**:
  - Включение/выключение звука
  - Включение/выключение вибрации

### 📱 Технические особенности

- **Оффлайн работа** - полностью автономное приложение
- **Нативное приложение** - APK для Android
- **Низкие требования** - работает на Android 7.0+
- **Малый размер** - ~5MB APK
- **Без рекламы** - чистый игровой опыт
- **Без встроенных покупок**

## 🚀 Установка

### Для пользователей

1. Скачайте APK файл
2. Включите установку из неизвестных источников в настройках Android
3. Установите приложение
4. Играйте!

### Для разработчиков

См. [BUILD.md](BUILD.md) для подробных инструкций по сборке.

Быстрый старт:
```bash
npm install
cordova platform add android
cordova build android
```

## 🎯 Геймплей

### Цель игры
Управляйте неоновой змейкой, собирайте еду, избегайте препятствий и своего хвоста. Набирайте максимальное количество очков!

### Советы по игре

1. **Используйте порталы стратегически**
   - Порталы могут спасти от столкновения
   - Планируйте маршрут через порталы заранее

2. **Power-ups - ваши друзья**
   - Магнит помогает собирать еду быстрее
   - Щит даёт право на ошибку
   - Удвоенные очки ускоряют набор рекорда

3. **Управление пространством**
   - Не загоняйте себя в угол
   - Оставляйте пути для отступления
   - Используйте центр поля для манёвров

4. **Начните с лёгкого уровня**
   - Изучите механики
   - Привыкните к управлению
   - Постепенно повышайте сложность
